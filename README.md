# E-Portfolio UAS PPL Mandiri — Muhammad Fikri Wibowo, S.Pd.

## Isi website
- `index.html`: pengarah ke halaman Profile.
- `profile.html`: beranda, profil, kontak, pengantar E-Portfolio.
- `artifak.html`: analisis mendalam modul siklus 1–4, tautan media/PPT, video praktik mengajar, CodeDeca, dan rekap nilai.
- `lampiran.html`: penilaian Guru Pamong (ditempatkan sebelum galeri), galeri terurut berdasarkan kegiatan mengajar, kegiatan di luar kelas, persiapan/pelaksanaan TKA, lalu penarikan PLP; daftar modul, media, CodeDeca, serta rekap nilai disusun dalam kelompok yang terpisah.
- `refleksi.html`: model guru yang dituju, filosofi mengajar, kekuatan, area pengembangan, dan rencana tindak lanjut.
- `assets/photos/`: foto dokumentasi yang dikirimkan pemilik portofolio.
- `assets/logos/`: logo UMS, PPG Calon Guru, dan SMA Negeri 7 Surakarta.
- `assets/dokumen/modul/`: empat PDF modul ajar.
- `assets/dokumen/media/`: empat PDF media presentasi per siklus.

## Catatan konten dan privasi
Analisis artefak dibangun dari isi modul yang diunggah. Dua konsistensi dokumen perlu ditinjau sebelum pengumpulan: (1) sampul modul Siklus 1 masih menyebut algoritma/pseudocode/flowchart sementara isi berfokus pada berpikir komputasional; (2) file modul Siklus 4 awalnya bernama Analisis Data tetapi sampul dan isi yang diterima membahas Literasi Digital. Durasi dan konsistensi jumlah/bobot asesmen pada Siklus 2 juga perlu diperiksa sebagaimana dicatat dalam analisis.

Tautan Google Drive disertakan sebagai sumber. Sebelum memublikasikan ke GitHub Pages, pastikan folder tidak membuka nama, nilai, atau data personal murid untuk akses publik. Data individu sebaiknya tidak dipasang pada website; gunakan data agregat yang sudah dianonimkan.

## Publikasi ke GitHub Pages
1. Buat repository GitHub dan unggah seluruh isi folder ini ke root repository.
2. Pertahankan struktur `assets/` termasuk folder `photos`, `logos`, dan `dokumen`.
3. Di **Settings → Pages**, pilih deployment dari branch `main` dan folder `/ (root)`.
4. Buka URL yang diberikan GitHub Pages. Periksa halaman Profile, Artifak, Lampiran, dan Refleksi di desktop serta ponsel.

## Catatan keterkaitan mata kuliah
Kaitan teori pada laman artifak menggunakan pendekatan dan konsep yang dinyatakan di dokumen: PBL, PjBL, CRT, Pembelajaran Mendalam, TPACK, berpikir komputasional, asesmen, refleksi, literasi informasi, dan etika digital. Nama mata kuliah yang disebutkan merupakan padanan konseptual dari daftar yang terlihat di PDF contoh E-Portofolio; cocokkan lagi dengan daftar resmi mata kuliah PPG Anda sebelum finalisasi.


## Galeri dokumentasi yang telah diperbarui
Foto ditampilkan dalam empat kelompok: (1) kegiatan mengajar, (2) kegiatan di luar kelas, (3) persiapan dan pelaksanaan TKA, dan (4) pelepasan/penarikan PLP. Foto penarikan PLP dipindahkan ke urutan paling akhir. Beberapa keterangan diperbaiki mengikuti konfirmasi pemilik portofolio.

Bagian “Daftar dokumen pendukung” ditata ulang menjadi tiga subbagian berlebar penuh: modul ajar Siklus 1–4, media presentasi Siklus 1–4, serta materi online dan rekap hasil belajar.

## Video praktik mengajar
Halaman Artifak menampilkan dua video YouTube. Pemutar menggunakan `youtube.com/embed` dengan `referrerpolicy="strict-origin-when-cross-origin"` serta meta referrer yang sesuai untuk membantu mengirim origin situs saat video disematkan melalui HTTPS. Uji dari URL GitHub Pages, bukan dengan membuka berkas HTML menggunakan `file://`. Jika browser atau setelan video tetap memblokir pemutar tertanam, tombol “Tonton di YouTube” tetap tersedia.
